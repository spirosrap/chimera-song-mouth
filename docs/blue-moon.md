# Blue Moon — one physical singer and the original orchestra

The user requested the full Frank Sinatra recording with its instrumental music
retained and the voice generated by CHIMERA's actual mouth engine. The 2:52
performance is appended to the twelve existing songs at `?song=blue-moon`.

The prepared score is the source of truth. Its 163 words were transcribed from
the supplied audio; an independent overlapping transcription resolved one word
boundary in the later verse. CMUdict supplies pronunciations, and a locally
cached phone model aligns those sounds to the isolated recording. The score has
200 syllables in 26 phrases, with brief consonants, sustained vowels and late
diphthong glides. Genuine quiet intervals split phrases even when a transcript's
word window absorbs a rest. Model blank frames are not themselves singing rests.

The same `planPerformance` / `planPart` / `renderPart` path used by Country Roads
produces the lead at 48 kHz. Continuous source pitch retains the melody and
vibrato; added vibrato is disabled. The simulated airflow, vocal folds and tract
produce every lead sample. The accompanying telemetry is captured from that
render, so the displayed mouth follows the articulations that made the sound.
No vocoder, ring modulation, processed original vocal, or estimated-vowel-only
render is used in the released lead. Pronunciation and timing remain approximate.

The stereo accompaniment stays on the recording's original clock. It uses the
separated orchestra during sung passages and restores the unchanged source
recording in genuine instrumental sections, with crossfades outside vocal tails.
Resampling and constant gain provide playback compatibility and headroom; there
is no tempo or pitch change. Separation can leave faint vocal traces. The final
release adds only 350 ms of tail silence, and preserves the full vocal ending.

The app retains separate voice/music levels, mute, solo, seeking, captions, mouth
word overlays and WAV export. Its normal singer editor can regenerate this
prepared performance; changing the words falls back to ordinary text planning.
The song's asset version is `phonetic-mouth-20261110`.

## Rebuild the physical singer

```sh
bun tools/render-prepared-voice.ts blue-moon lead
bun run content:manifest
bun run test --timeout 15000
bun run typecheck
bun run build:static --base=/chimera-song-mouth/
```

The voice renderer reads the prepared phonetic score and preserves the backing,
score and default mixer levels. It requires ffmpeg but no source recording,
transcription model or alignment cache. The raw supplied recording and analysis
models are not included in the repository.

Validation covers source-clock timing, the full vocal ending, audible phrases,
finite moving mouth telemetry, real phrase rests, stereo accompaniment and mix
headroom. All 228 previous public files are preserved byte for byte. Repository
checks and the subfolder build are used; browser interaction and visual/recording
QA were not performed because browser access was previously declined.
